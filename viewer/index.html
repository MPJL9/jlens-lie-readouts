notes

Both lenses read the same saved residual streams. Logit lens = the unembedding applied to the residual stream directly. J-lens = the unembedding applied after the published Jacobian lens map for that layer (the identity at the final layer, so the final row is the model's own output). Readouts start at the last user-prompt token; earlier tokens were not saved.

Labels. "label" is the LLM judge's verdict on the response; "stance" is whether the response affirms the true statement, the false one, or neither; for lies, the judge's quote of the false claim is shown under the response. The two badges above the prompt give the judge's label (lie / truth) and the model's self-report answer under the selected wording (admits / denies); the item list shows both for every transcript. With "hide labels" on, the judge's label, the stance, the quote and the label filter are hidden, and the address bar holds only an item number. Unrelated chats have no label.

Positions. The prefix (last user-prompt token to the post-response boundary) comes from one forward pass shared by every wording; the question, answer and post-answer boundary come from that wording's own pass.

Yes − No score = log-sum-exp of the Yes-token scores minus that of the No tokens, at each layer.
